# Venkata Surya Prakash – Resume (HTML, CSS)

This repository contains a **landing page** of **Cursor** built using plain HTML and CSS.

---

## Overview

This website is structured using modern HTML5 semantic elements and CSS for layout and readability.  
The focus is on clean structure, spacing.

The page containes the following sections:

- Header
- Main
    |- Hero Section
    |- Trusted By 
    |- Features Section
    |- Testimonials
    |- Use Cases
    |- Updates
    |- Team
    |- Highlights
    |- Final CTA
- Footer

## Project Setup

Clone the repository:

```bash
git clone https://github.com/J-VSuryaPrakash/WDC-2026.git
````

Navigate to the project directory:

```bash
cd '.\Dev Tool Landing Page\'
```

Open index.html in a web browser
or run it using Live Server (VS Code extension).
